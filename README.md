
# Computational Physics: Projectile Motion Simulation

**Author:** Brian Ryan

## Project Overview

This project demonstrates a Python-based computational physics simulation of projectile motion under gravity and linear air resistance.

The simulation uses the fourth-order Runge-Kutta (RK4) numerical integration method and compares numerical results against analytical solutions.

## Objectives

- Model projectile motion mathematically.
- Implement numerical integration using Python.
- Analyze the effects of gravitational acceleration and air resistance.
- Compare numerical and analytical solutions.
- Evaluate computational accuracy through error analysis.
- Generate scientific visualizations.

## Physical Model

The equations of motion are:

dx/dt = vx

dy/dt = vy

dvx/dt = -kvx

dvy/dt = -g - kvy

Where:

- g = 9.81 m/s²
- k = linear drag coefficient divided by mass
- vx = horizontal velocity
- vy = vertical velocity

## Numerical Method

The simulation uses the fourth-order Runge-Kutta (RK4) method to solve the system of differential equations.

Four intermediate slopes are calculated at each time step to improve numerical accuracy.

## Analytical Validation

The numerical solution is compared against the analytical solution for the same physical model.

The program calculates:

- Maximum projectile height
- Horizontal range
- Flight duration
- Maximum position error
- Mean position error

## Model Limitations

The simulation assumes constant gravitational acceleration and linear air resistance. It does not account for wind, changing atmospheric density, or three-dimensional motion.
